# CBC Wine Menu

Custom WordPress plugin for managing a digital wine menu with QR code access.

## Project goals

- Digital wine menu
- QR code access per table
- Temporary 30-minute sessions
- 20 table entry points
- Italian and English support
- WordPress administration interface
- Future support for Wi-Fi based access validation

## Local development

The project uses:

- WordPress
- PHP 8.3
- MariaDB 10.11
- Apache
- Lando
